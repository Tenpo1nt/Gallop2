# Gallop 🐴

A web-based Physical Therapy management platform built for Team H.O.R.S.E (COMP490/491).

## What it does
Gallop digitizes the workflow between physical therapists and their patients. 
Admins pre-register users, PTs manage their assigned patients and assign 
workouts, and patients track their rehab progress — all through a role-based 
dashboard system.

## Tech Stack
- **Frontend:** React + Vite
- **Backend/Database:** Supabase
- **Deployment:** Vercel

## Roles
- **Admin** — manages users and system access
- **Physical Therapist (PT)** — views assigned patients, assigns workouts
- **Patient** — tracks assigned rehab workouts

## Getting Started
1. Clone the repo
2. Run `npm install`
3. Add your `.env` with Supabase credentials
4. Run `npm run dev`
